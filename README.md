# iCalendar API GUI

A Python-based graphical user interface (GUI) application designed to interact with iCalendar data. This project provides an intuitive way to view and manage calendar events through a user-friendly cyber-punk-esk interface.

## Table of Contents

- [Overview](#overview)
- [Features](#features)
- [Installation](#installation)
- [Usage](#usage)
- [Contact](#contact)

## Overview

The **iCalendar API GUI** project aims to simplify the process of interacting with iCalendar data. Whether you're looking to display upcoming events, update your calendar, or integrate calendar functionality into your workflow, this tool provides a straightforward solution using a clean, graphical interface.

## Features

- **Intuitive GUI:** Easy-to-use interface for managing calendar events.
- **Cross-Platform:** Built with Python, ensuring compatibility across various operating systems.
- **Customizable:** Options to tailor the interface and functionalities to suit your needs.

## Installation

### Prerequisites

- **Python 3.6+**: Ensure that you have Python installed.
- **pip**: Python package installer.

### Steps

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/EthanMasters23/icalendar_api_gui.git
   cd icalendar_api_gui
   ```

2. Install Dependencies:

It is recommended to use a virtual environment:

```bash
python -m venv venv
source venv/bin/activate    # On Windows, use: venv\Scripts\activate
pip install -r requirements.txt
```

## Usage

After installation, run the application with:

```bash
python main.py
```
